# 에이스엔지니어링 해외사업팀 일일보고

공유 링크: https://crush981231-spec.github.io/ace-daily-report/

복잡한 업무 분류·진행률·투입시간 대신 육하원칙으로 간단히 작성하는 일일보고입니다. 제공받은 회사 로고를 사용합니다.

## 작성

1. 작성자와 보고 날짜를 선택합니다.
2. 누가, 언제, 어디서, 무엇을, 어떻게, 왜를 입력합니다.
3. 결과나 결정사항이 있으면 추가합니다.
4. 정리된 문장을 확인하거나 직접 고친 뒤 저장·복사·인쇄합니다.

작성자와 상대방은 다른 항목입니다. 누가에는 업무를 함께 진행한 상대방이나 참석자를 적습니다.

## 작성자 표시 순서

남종현 과장, 김요한 과장, 김상현 과장, 김민구 대리, 조병주 대리, 이재웅 주임, 이수진 주임.

## 예시

금일 오후 4시 부산 사무실에서 TEMPO 측 수석 엔지니어 Keenan과 프로토타입의 단열 성능을 개선하기 위해 인슐레이션 자재를 A에서 B로 변경하는 방안을 논의했으며, B로 변경하기로 결정하였다.

## 저장과 보안

- 사이트와 이름·직급·로고가 포함된 소스는 공개됩니다. 작성자 선택은 사용자 인증이나 접근 제한이 아닙니다.
- 보고서는 현재 브라우저에만 저장됩니다. 실제 회사 제출·결재·팀 공유·기기 간 동기화 기능은 없습니다.
- 이전 양식의 브라우저 저장 자료는 삭제하지 않고 별도로 보관합니다.
- 브라우저 데이터를 삭제하거나 기기를 바꾸기 전 기록을 내보내 안전하게 보관하세요.
- 사내 보안·보고 절차를 확인한 뒤 사용하세요.

## 실행 및 배포

index.html 단일 파일입니다. 외부 라이브러리나 서버 설치가 필요 없습니다. GitHub Pages는 main 브랜치의 /(root)에서 배포합니다. 보고서 파일이나 JSON 내보내기 자료는 공개 저장소에 업로드하지 마세요.
