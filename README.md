# ACE Engineering 일일보고

회사의 공식 사내 양식이 아닌 일반 일일보고 양식 기반의 독립적인 도구입니다.

## 실행과 기능

index.html을 브라우저에서 열면 실행됩니다. 별도 설치나 외부 라이브러리가 없습니다. 금일 업무, 진척률, 투입시간, 익일 계획, 이슈와 요청사항을 기록합니다. 보고서 작성/수정/검색/삭제, 자동 임시저장, 대시보드, 인쇄/PDF 저장, CSV 내보내기, JSON 백업/복원을 제공합니다.

## 중요한 제한사항

- 데이터는 현재 기기/브라우저에만 저장됩니다. 실제 사내 제출/결재/다중 사용자 공유/서버 동기화는 제공하지 않습니다.
- 브라우저 데이터 삭제 또는 접속 주소 변경 시 저장 자료가 보이지 않을 수 있습니다. 정기적으로 JSON 백업을 보관하세요.
- 회사 보안 정책을 확인한 뒤 사용하세요.
- 공개 사이트 자체에는 접근 제어가 없습니다. 팀 운영에는 별도 인증/권한과 보안 검토된 서버가 필요합니다.

## GitHub Pages 배포

1. 저장소에 index.html과 README.md를 업로드합니다.
2. Settings > Pages > Build and deployment > Deploy from a branch를 선택합니다.
3. main 브랜치, /(root)를 선택한 뒤 Save를 누릅니다.
4. 배포 완료 후 Pages에 표시되는 사이트 주소로 접속합니다.

공개 저장소에는 프로그램 소스만 올리세요. 보고서 JSON 백업, CSV 또는 사내 문서는 업로드하지 마세요.
