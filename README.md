# 에이스엔지니어링 해외사업팀 일일보고

공유 주소: https://crush981231-spec.github.io/ace-daily-report/

## 조회

로그인이나 이메일 승인이 필요 없습니다. 제출내역에서 날짜와 작성자를 선택하고 조회하면 서버에 제출된 보고서를 볼 수 있습니다. 제출한 내용은 인터넷에서 누구나 열람할 수 있으므로 기밀·개인정보를 입력하지 마세요.

## 제출·수정

Google 로그인 후 누구나 보고서를 제출할 수 있습니다. 사전 등록된 특정 이메일만 허용하는 방식이 아닙니다. 작성자 이름은 다음 7명 중 선택합니다.

남종현 과장, 김요한 과장, 김상현 과장, 김민구 대리, 조병주 대리, 이재웅 주임, 이수진 주임.

누가·언제·어디서·무엇을·어떻게·왜와 결과를 작성하고 최종 문장을 확인한 후 보고서 제출을 누릅니다. 본인 Google 계정으로 제출한 보고서는 수정·삭제할 수 있습니다. 초기 관리자 계정은 전체 보고서를 관리할 수 있습니다. 작성자 선택은 실명 인증이 아닙니다.

## 저장

제출된 보고서는 Firebase Cloud Firestore 공용 서버에 저장됩니다. 새 브라우저에서도 같은 날짜·작성자로 조회할 수 있습니다. Google 로그인은 제출자 소유권 구분에 사용되며 이메일은 공개 보고서에 저장하지 않습니다. Firebase Authentication에는 계정 정보가 저장됩니다.

데이터베이스: 서울 asia-northeast3, Standard, Spark 무료 요금제. 카드 등록, 유료 요금제 자동 전환, 유료 예약 백업은 설정하지 않았습니다. 무료 한도 초과 시 기능이 제한될 수 있습니다.

작성 중 임시 내용과 이전 양식의 기기 기록은 자동으로 제출하지 않습니다. 이전 기기 기록을 불러온 뒤 명시적으로 제출하세요. 예시 자료는 실제 보고서로 제출하지 않습니다.

## 구성

- index.html: 육하원칙 작성, 기기 임시저장
- shared.js: Google 로그인, 실제 제출, 공개 조회, 소유자 수정·삭제
- firebase-config.js: 공개 웹 클라이언트 식별 설정. 관리자 비밀번호/서비스 계정 키가 아닙니다.
- firestore.rules: 누구나 조회, 인증된 제출자만 작성·본인 기록 수정/삭제하는 서버 규칙

GitHub Pages: main /(root). 실제 업무 보고서, 인증 토큰, 서비스 계정 키를 GitHub에 업로드하지 마세요. 회사 보안 정책과 공개 가능 범위를 확인한 뒤 사용하세요.
