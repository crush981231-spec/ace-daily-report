# 에이스엔지니어링 해외사업팀 일일보고

공유 링크: https://crush981231-spec.github.io/ace-daily-report/

## 로그인 없는 사용

Google 로그인, 회원가입, 특정 이메일 승인 없이 누구나 제출·수정·조회할 수 있습니다. 작성자를 선택해 육하원칙과 결과를 입력하고 보고서 제출을 누르세요. 제출내역에서 날짜와 작성자를 선택하면 공용 서버 자료를 볼 수 있고, 수정으로 불러와 수정 제출할 수 있습니다. 작성자는 남종현 과장, 김요한 과장, 김상현 과장, 김민구 대리, 조병주 대리, 이재웅 주임, 이수진 주임 순서입니다.

## 날짜별 작성 현황

작성 현황 탭에서 보고일을 선택하면 지정된 7명 전원의 작성완료/미작성, 최초 제출 시각, 최근 수정 시각을 볼 수 있습니다. 시각은 한국시간입니다. 서버에 실제로 제출한 보고서만 작성완료로 집계하며 임시저장은 포함하지 않습니다. 같은 날 여러 보고서를 제출하면 건수를 함께 표시합니다. 서버 조회 실패는 미작성으로 표시하지 않습니다.

## 팀장 승인

제출내역의 각 보고서에 팀장 승인 버튼이 있습니다. 작성 현황에서도 한 건인 보고서는 바로 승인할 수 있고, 여러 건이면 보기로 각 보고서를 확인합니다. 승인 완료 여부와 승인 시각은 공용 서버에 저장됩니다. 보고서를 다시 제출하면 이전 승인은 새 내용에 유효하지 않으므로 승인대기로 표시됩니다. 변경 전 내용을 보고 승인하려는 요청은 거절하고 새로 조회하도록 안내합니다.

기존 로그인 없는 방식을 유지하므로 승인 버튼도 누구나 누를 수 있습니다. 팀장 승인은 업무 상태 표시이며 실제 승인자 신원을 인증하는 기능은 아닙니다.

## 공개 범위 주의

링크를 아는 누구나 다른 사람의 보고서도 수정할 수 있습니다. 작성자 선택은 실명 인증이 아닙니다. 기밀·개인정보는 입력하지 마세요. 전체 삭제는 공개 화면에서 제공하지 않으며 관리자가 Firebase Console에서 처리합니다.

## 저장

제출 자료는 서울 리전의 Firebase Cloud Firestore 공용 서버에 저장됩니다. 작성 중 임시 내용과 이전 양식의 기기 기록은 자동으로 제출하지 않습니다. Spark 무료 요금제이며 카드 등록·유료 전환·유료 예약 백업을 설정하지 않았습니다. 무료 한도 초과 시 기능이 제한될 수 있습니다.

## 구성

index.html, shared.js, firebase-config.js는 GitHub Pages main /(root)에서 배포합니다. firestore.rules는 서버에서 보고서 형식·7명 작성자·최초 생성시각 보존을 검사합니다. 보고서와 해당 승인 기록에만 정해진 형식의 쓰기를 허용합니다. Firebase 웹 설정은 공개 클라이언트 식별 정보이며 비밀키가 아닙니다. 인증 토큰·서비스 계정 키·업무 기록 파일을 GitHub에 올리지 마세요.
